## 📂 Como este repositório foi organizado

Todas as capturas de tela originais foram exportadas da Steam (`userdata/760/remote`) e organizadas através de scripts em PowerShell com nomenclatura padronizada e temporal (`NOME_JOGO_DATA_NUMERO.jpg`).
